Privacidad de trackingcompras

trackingcompras es una app de uso personal, hecha por Doble Falta SpA para su fundador. No está disponible para otras personas.

Qué datos usa. Con permiso de solo lectura de Gmail, la app busca los mails de compras y envíos de una sola cuenta. De esos mails guarda la tienda, los productos, el número de pedido, el código de seguimiento, el courier, las fechas y el identificador del mail. El resto del correo no se guarda.

Con quién se comparten. El texto de los mails de compras y envíos se envía a la API de Anthropic para extraer esos datos. Los códigos de seguimiento se envían a Ship24 para consultar su estado. Los datos se guardan en un servidor en Railway, y los avisos se mandan con el servicio de notificaciones de Apple. Nada se vende ni se usa para publicidad.

Datos de Google. El uso de la información recibida de las APIs de Google se ajusta a la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

Cómo borrar los datos. El acceso a Gmail se quita en myaccount.google.com/permissions. Los datos guardados se borran escribiendo a daniel@doblefalta.dev.

Actualizada el 22 de octubre de 2026.

Landing page estática (HTML/CSS/JS puro) para el estudio personal de apps llamado "doble falta".

**Why:** Portafolio/landing para proyectos de apps con foco en humor y simplicidad.

**How to apply:** Cuando Daniel haga cambios al landing, recordar la estructura y decisiones de diseño tomadas.

Ubicación: `/Users/daniel/workspace/landing/`

Archivos:
- `index.html` — markup principal
- `style.css` — estilos pixel art (fuentes: Press Start 2P + VT323)
- `script.js` — fade-in scroll + konami code easter egg
- `logo.js` — pixel art canvas del tenista (16×20px, escala 2.5x)
- `.claude/launch.json` — servidor python3 en puerto 3000

Concepto: apps con humor y simplicidad. "Hacemos apps. Unas sirven. Las otras quizás, pero al menos hay salud."
